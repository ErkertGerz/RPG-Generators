# RPG Generator (KitoGerz)

Демонстрационный веб-прототип генератора персонажей Warhammer 40,000 Roleplay.

## Запуск локально

В Visual Studio Code откройте папку проекта и запустите `index.html` с помощью расширения **Live Server**.

Также можно запустить встроенный сервер Python из корневой папки проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000` в браузере. Не открывайте `index.html` напрямую через `file://`: браузер может заблокировать загрузку JSON через `fetch()`.

## Публикация на GitHub Pages

Загрузите содержимое папки в репозиторий GitHub. Откройте **Settings → Pages**, выберите источник публикации из нужной ветки и корневую папку репозитория. Учитывайте регистр букв в названиях `Data/Akhetyps/space_marine.json`.

## Что работает

- Главная страница и раздел Warhammer 40,000.
- Генерация персонажа по выбранному уровню, архетипу, легиону/варбанде и верованию.
- Характеристики, стартовые навыки, таланты, трейты и снаряжение.
- Последовательные тестовые имена: `Тестовое 1`, `Тестовое 2`, `Тестовое 3` и так далее.
- Экспорт результата в универсальный JSON, текстовый файл `.txt` и копирование текстовой карточки.
- Незавершённые разделы обозначены текстом «Раздел в разработке».

## Экспорт в Roll20 и Foundry VTT

Сейчас доступны два переносимых варианта:

- **JSON** — структурированные данные персонажа для хранения, обработки и дальнейшей конвертации.
- **Текстовая карточка** — её можно скопировать в Bio/Notes или описание персонажа в VTT.

Это пока не полноценный прямой импорт в лист персонажа. Roll20 поддерживает импорт только там, где его предусматривает конкретный лист персонажа или дополнительный инструмент. Foundry VTT позволяет импортировать JSON экспортированных актёров, но поля внутри `system` зависят от установленной игровой системы и её модели данных. Поэтому для прямого импорта нужно выбрать конкретную систему/лист, а затем написать адаптер, который сопоставит поля генератора с нужными полями листа.

Официальные материалы:

- Roll20 — [Character Sheet Import](https://wiki.roll20.net/Character_Sheets/Import)
- Foundry VTT — [Actors: import and export JSON](https://foundryvtt.com/article/actors/)
- Foundry VTT — [System Data Models](https://foundryvtt.com/article/system-data-models/)

## Структура проекта

```text
RPG_Generator_KitoGerz_MVP/
├── index.html
├── app.js
├── style.css
├── README.md
└── Data/
    └── Akhetyps/
        └── space_marine.json
```

- `space_marine.json` — таблицы уровней, архетипов, характеристик, списков снаряжения, навыков, талантов и трейтов.
- `app.js` — логика генерации, интерфейс и экспорт персонажа.
- `index.html` — разметка страниц.
- `style.css` — стили интерфейса.

## Примечание к игровым правилам

В текущем файле используются архетипы и расширенные таблицы снаряжения из Excel-прототипа «Генератор Астартес Врагов». В них есть хаоситские/ренегатские варианты. Если проект должен создавать только лоялистов, эти варианты стоит отделить в самостоятельный JSON.
